Where the connection is in the code

  • js/api-client.js → fetch('/api/bookings', …) sends the booking JSON to the server.
  • server/server.js → POST /api/bookings checks, calculates the price, writes to the database.
  • server/schema.sql → the tables from the ER diagram + the trigger that blocks double bookings.
  • booking.js did not change: it still calls HotelApi.createBooking().
